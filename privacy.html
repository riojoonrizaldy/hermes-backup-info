Kebijakan privasi

Hermes Backup Pribadi dikelola oleh Rio Rizaldy untuk penggunaan pribadi, bukan layanan backup bagi masyarakat umum.

Data dan tujuan penggunaan

Aplikasi memproses data instalasi Hermes milik pengelola, termasuk konfigurasi, memori, skill, riwayat sesi, dan data profil yang tercakup dalam arsip. Data digunakan untuk pencadangan dan pemulihan, bukan periklanan atau pelatihan model melalui utilitas backup ini.

Izin Google

Izin https://www.googleapis.com/auth/drive.file digunakan untuk membuat dan mengelola file yang dibuat atau dibuka melalui aplikasi, serta memeriksa metadata ukuran dan checksum unggahan. Token OAuth disimpan pada server pengelola untuk menjalankan tugas terjadwal; token tidak dipublikasikan melalui situs ini.

Penyimpanan dan perlindungan

Arsip dienkripsi menggunakan kunci publik GPG sebelum diunggah ke Google Drive. Kunci privat untuk dekripsi disimpan terpisah oleh pengelola. Arsip terenkripsi dapat disimpan pada server lokal dan Google Drive; salinan ZIP sementara dihapus setelah tahap pembuatan dan enkripsi, termasuk saat terjadi kegagalan pada tahap tersebut. Enkripsi mengurangi risiko, tetapi bukan jaminan keamanan mutlak.

Pihak lain dan masa simpan

Google Drive menyimpan arsip terenkripsi sebagai penyedia penyimpanan. Aplikasi tidak menjual data atau membagikan arsip secara publik. Salinan lokal dan Drive disimpan sampai dihapus secara manual oleh pengelola; belum ada retensi otomatis. Halaman informasi ini dihosting melalui GitHub Pages setelah diterbitkan, dan permintaan pengunjung diproses sesuai kebijakan layanan hosting tersebut.

Pencabutan akses dan penghapusan

Pengelola dapat mencabut izin aplikasi melalui pengaturan koneksi pihak ketiga pada Akun Google. Pencabutan menghentikan akses berikutnya, tetapi tidak otomatis menghapus arsip yang sudah tersimpan. Arsip lokal dan Google Drive perlu dihapus terpisah; sampah Drive juga memiliki aturan penyimpanan tersendiri.
